# A 股超短单一工作簿滚动维护设计

## 目标

盘前 Skill 永久维护同一个工作簿 `review/A股超短交易工作台.xlsx`，不再按日期创建新文件或新工作表。当前执行页面保持简洁，历史判断和交易数据以追加行的方式保留，便于复盘、审计和统计个人期望值。

## 工作表与更新策略

| 工作表 | 更新方式 | 用途 |
|---|---|---|
| 持仓总览 | 每次运行覆盖当前区域 | 展示最新账户、持仓、浮动盈亏、风险占用和检查结果 |
| 参数设置 | 按需更新，不自动清空 | 保存账户净值、真实费用、风险档和压力参数 |
| 次日策略 | 每次运行整体覆盖 | 只保留最新有效的高开、平开、低开和极端低开剧本 |
| 来源与检查 | 每次运行覆盖当前区域 | 保存本次数据来源、缺失项、公式检查和模型状态 |
| 运行记录 | 每次运行追加一行 | 保存运行时间、数据截止、竞价阶段、三轴环境、唯一模式、风险档、总仓上限、快照 ID 和结论 |
| 候选记录 | 每只候选每次运行追加一行 | 保存候选所属板块、层级、最坏入场、止损、目标、净盈亏比、结论和淘汰原因 |
| 交易日志 | 新交易追加，平仓后回填原行 | 一笔完整交易只占一行，并引用对应快照 ID |

## 同日多次运行

- 09:15 前、09:15–09:20、09:20–09:25 和 09:25 后运行都覆盖当前页面。
- 每次运行生成唯一快照 ID，并在 `运行记录` 追加一行；不能用后一次运行覆盖前一次历史判断。
- 同一候选在竞价前和竞价后重新评估时，在 `候选记录` 分别追加记录，以快照 ID 区分。
- 交易日志不得因盘前策略覆盖而删除或重建。

## 数据一致性

- 工作簿路径固定，不允许因日期变化另存新文件。
- `持仓总览`、`次日策略` 和 `来源与检查` 的当前数据必须来自同一个快照 ID。
- 追加历史前先检查快照 ID；完全相同的快照不得重复写入。
- 表头固定，历史表只允许向下追加；禁止插入破坏公式或统计范围的任意列。
- 红涨/盈、绿跌/亏的条件格式适用于当前页和历史盈亏字段。

## 异常处理

- 固定工作簿不存在时才创建初始文件。
- 工作簿存在但被占用、损坏或缺少必要工作表时，停止写入并报告原因，不创建替代日期文件。
- 输入不完整时仍可追加带 `INCOMPLETE` 状态的运行记录，但不得输出精确股数。
- 任一公式出现 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或 `#N/A` 时，不得把本次更新标记为成功。

## 验收标准

1. 连续两天运行后，项目中仍只有一个工作簿。
2. 第二天的 `次日策略` 已覆盖第一天内容。
3. 两天的 `运行记录`、`候选记录` 和交易日志历史仍然存在。
4. 同日竞价前和竞价后运行产生两个不同快照，当前页只显示后者。
5. 重复写入同一快照 ID 时不会生成重复历史行。
6. 公式错误为零，红涨/盈和绿跌/亏格式保持正确。
